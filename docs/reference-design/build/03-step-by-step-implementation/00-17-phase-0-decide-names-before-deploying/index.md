# Phase 0 — Decide names before deploying

Use stable identifiers.

Example:

```text
Kubernetes namespace: minecraft
Public host: play.example.com

Runtime IDs:
  vanilla-current
  backrooms-current
  fantasy-1.20.1-forge

Backend logical IDs:
  lobby-1
  survival-main
  backrooms-001
  fantasy-kingdom-001
```

Do not use user-facing display names as primary keys.
